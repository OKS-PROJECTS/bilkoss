## [0.1.0] — 2026-08-29

### Added

- Initial scaffold: Vite + React 19, Tailwind v4 (layout only), react-router-dom v7.
- Design-token layer (`src/styles/theme.css`) — brand ramp, semantic roles, the
  `--app-*` semantic layer, light + dark themes.
- App shell — recursive sidebar, header control cluster, inner layout frame.
- Composition layer (`src/Components/ui/`) built entirely from oks-ui primitives.
